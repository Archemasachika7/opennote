# Batch A Plan (approved 2026-11-10)

Spec: docs/superpowers/specs/2026-11-09-opennote-design.md + the Batch A design approved in chat.

- A1 Library: favourites, trash (restore / delete forever / 30-day purge), grid|list view, select mode (move, favourite, trash), sort by name/created/modified/pages. Delete = move to Trash.
- A2 Text pages: underline, text colour, highlight, tables, Outline sidebar tab; PDF export handles them.
- A3 `.opennote` backup: zip export of a notebook (pages, strokes, objects, blobs); import makes a copy.
- A4 JPG export and page selection (all / current / ranges like "2-5, 8") for PDF and JPG.
- A5 PDF import (pdf.js, offline): new notebook or insert; PDF page = ink page with PDF background image; eraser cannot touch it; text layer searchable.
- A6 Rotate ink pages 90 degrees (content rotates with the page).
- A7 Go to page number.

Each item: failing test first, then code; full unit + e2e suite and build before push.
